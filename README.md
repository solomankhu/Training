หน้าเว็บสำหรับทำแบบทดสอบหลังการอบรม เปิดบนมือถือผ่านการสแกน QR

**เดโม:** https://solomankhu.github.io/Training/?role=surveyor&session=DEMO

## ทำไมถึงแยกเป็นสองที่

| ส่วน | อยู่ที่ไหน | มีอะไร |
|---|---|---|
| หน้าเว็บ | GitHub Pages (repo นี้ · สาธารณะ) | `index.html` + `items.js` — โจทย์และตัวเลือก |
| ตัวรับคำตอบ | Google Apps Script (ส่วนตัว) | `Code.gs` + `Keys.gs` — **เฉลย คะแนน คำอธิบาย** |

**`Keys.gs` ไม่อยู่ใน repo นี้ และต้องไม่ถูกเพิ่มเข้ามา**

เฉลยไม่เคยถูกส่งไปที่เบราว์เซอร์ หน้าเว็บจึงคำนวณคะแนนเองไม่ได้แม้จะแก้ JavaScript ของมันเอง
ผู้สอบเห็นแค่ "ส่งคำตอบเรียบร้อย" ผู้สอนรวบรวมคะแนนจาก Google Sheet ภายหลัง

นี่ไม่ใช่การตั้งใจไม่แสดงผล แต่เป็นเรื่องที่**ทำไม่ได้โดยโครงสร้าง** — และนั่นคือเหตุผลที่ต้องแยก

> ⚠️ โจทย์ในไฟล์ `items.js` เปิดให้ทุกคนอ่านได้ เพราะ repo นี้เป็นสาธารณะ
> แบบทดสอบนี้เป็นแบบเปิดหนังสือและไม่มีผลต่อการเข้าถึงระบบ จึงรับได้
> แต่ **อย่าใส่อะไรที่เป็นความลับลงในโจทย์**

## ติดตั้ง

### 1–6. ฝั่ง Google

ทำตาม `SETUP.md` ในรีโปหลัก (สร้างชีต → วาง `Code.gs` + `Keys.gs` → `selfTest` → Deploy → ตั้งการลบข้อมูลอัตโนมัติ)

ตอน Deploy ต้องตั้ง **Execute as: Me** และ **Who has access: Anyone** — ผู้เข้าอบรมภาคสนามส่วนใหญ่ไม่มีบัญชี Google

เสร็จแล้วจะได้ URL หน้าตาแบบนี้ ให้คัดลอกไว้:

```
https://script.google.com/macros/s/AKfycb.../exec
```

**ทดสอบว่า deploy ติดจริง:** เปิด URL นั้นในเบราว์เซอร์ ต้องเห็น JSON ประมาณ

```json
{"ok":true,"service":"SSM exam endpoint","bank_version":"items@...","roles":["surveyor","gis",...]}
```

### 7. ต่อหน้าเว็บเข้ากับ Apps Script

แก้บรรทัดเดียวใน `index.html`:

```js
var ENDPOINT = 'PASTE_YOUR_APPS_SCRIPT_URL_HERE';
```

วาง URL จากขั้นที่ 6 ลงไป แล้ว commit

ถ้าลืมขั้นนี้ หน้าเว็บจะขึ้นแถบเตือนบนหัวจอทันทีที่เปิด ไม่ปล่อยให้ไปพังตอนกดส่ง

### 8. เปิด GitHub Pages

**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

รอสักครู่แล้วเปิด `https://solomankhu.github.io/Training/`

### 9. สร้าง QR

หนึ่งใบต่อหนึ่งบทบาท:

```
https://solomankhu.github.io/Training/?role=<บทบาท>&session=<รหัสรุ่น>
```

| บทบาท | ค่า `role` |
|---|---|
| ผู้ดูแลระบบ | `admin` |
| หัวหน้าเขต | `zonehead` |
| นักสำรวจ | `surveyor` |
| ผู้ใช้งาน GIS | `gis` |
| รถตัดอ้อย | `cutter` |
| จุดบริการ | `servicepoint` |

`session` ใช้ได้เฉพาะ `A-Z a-z 0-9 - _` เปิดรุ่นใหม่เปลี่ยนแค่ค่านี้

**ทำ QR แยกใบต่อบทบาท ไม่ใช่ใบเดียวแล้วให้เลือกเอง** — เลือกผิดครั้งเดียวคือได้ข้อสอบผิดชุดทั้งฉบับ และจะรู้ตอนดูคะแนนซึ่งสายไปแล้ว

### 10. ทดสอบส่งพร้อมกัน (ห้ามข้าม)

ให้คน 5–10 คนกดส่งพร้อมกันจริง แล้วนับแถวในชีต

หน้าเว็บมี retry อัตโนมัติ 4 ครั้ง (0.9 / 1.8 / 3.6 วินาที) และเก็บร่างไว้ในเครื่อง ถ้าส่งไม่ผ่านคำตอบจะไม่หาย กดส่งใหม่ได้ ฝั่งเซิร์ฟเวอร์ใช้ `LockService` กันเขียนทับ และ `client_token` กันบันทึกซ้ำ

**นี่คือสิ่งเดียวที่พิสูจน์ว่าเพดานการรันพร้อมกันของ Apps Script รับรุ่นจริงไหว** — อย่าเดา

## ห้ามแก้ `items.js` ด้วยมือ

ไฟล์นี้ถูก generate จาก `docs/training/exam/items/*.toml` ในรีโปหลักด้วย `scripts/ops/exam_build.py`
แก้ที่นี่ = คลังข้อแตกเป็นสองชุด และ `exam_gate.py` จะไปตรวจชุดที่ไม่ได้ใช้จริง

อยากแก้โจทย์ → แก้ TOML ในรีโปหลัก → รัน generator → คัดลอกไฟล์ที่ได้มาที่นี่

รีโปหลักมี workflow `exam-publish` ที่ทำขั้นคัดลอกนี้ให้เอง และ **ตรวจก่อน push ทุกครั้ง**
ว่าไม่มีเฉลย ไม่มีไฟล์ต้นทาง และไม่มีร่องรอยความลับหลุดมาที่นี่ (`exam_publish_guard.py`)
ถ้ามีอะไรหลุด งานจะล้มก่อน push — ไม่ใช่มาพบทีหลังตอนของอยู่บนที่สาธารณะแล้ว

## คะแนนไปอยู่ที่ไหน

หน้านี้ **ไม่แสดงคะแนน** ให้ผู้สอบเลย ส่งเสร็จเห็นแค่ว่าส่งสำเร็จ (มติ D15)
ไม่ใช่เพราะเลือกไม่แสดง แต่เพราะ**หน้านี้ไม่มีเฉลยอยู่ในมือ** จะคำนวณเองก็ทำไม่ได้

คะแนนถูกตรวจและเก็บที่ฝั่ง Apps Script ผู้ตรวจเปิดชีตแล้วสั่ง
**แบบทดสอบ SSM → อัปเดตอันดับคะแนน** เพื่อดูอันดับ **แยกตามบทบาท**
รายละเอียดการจัดอันดับอยู่ใน `docs/training/exam/appsscript/SETUP.md`

## สถานะ

คลังข้อเป็น **ข้อสอบจริง ครบทั้ง 6 บทบาท** บทบาทละ 40 ข้อ (ข้อกลาง 10 + เฉพาะบทบาท 30) รวม 190 ข้อไม่ซ้ำ
ทุกข้อผ่านด่านตรวจเลข blueprint และเขียนจากพฤติกรรมที่ตรวจกับโค้ดและฐานข้อมูลจริงแล้ว

แถบเตือนสีส้มบนหัวจอเหลือหน้าที่เดียว คือเตือนเมื่อยังไม่ได้ตั้ง `ENDPOINT` — ถ้าตั้งแล้วจะซ่อนตัวเอง
ฉะนั้นถ้าเห็นแถบส้มขึ้นหลังดีพลอยรอบใหม่ แปลว่าลืมวาง URL `/exec` ไม่ใช่เรื่องคลังข้อ
